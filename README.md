# Слово · перевод богослужения

Пульт оператора для распознавания русской речи и показа английских субтитров на отдельном экране или в OBS. Аудио передаётся сервису распознавания; приложение не сохраняет аудиозапись.

## Локальный запуск

Требуется Node.js 22.13+ и Python 3 для тестов SQLite.

```sh
npm ci
npm run configure
npm run db:migrate
npm run dev
```

Откройте http://localhost:3000 — локальный пульт работает без пароля. Этот режим включён только в локальной конфигурации и только для localhost/127.0.0.1. На опубликованном сайте пароль остаётся обязательным.

В `.env` заполните `OPENAI_API_KEY` для распознавания и ключ выбранного сервиса перевода: по умолчанию `GEMINI_API_KEY`. Провайдер и модель задаются через `TRANSLATION_PROVIDER`, `TRANSLATION_MODEL` и `ASR_MODEL`. Для перевода через Claude укажите `TRANSLATION_PROVIDER=anthropic` и `ANTHROPIC_API_KEY`. Модель Claude (Haiku 4.5, Sonnet 5.5, Opus 5.5, Fable 5.1) и уровень размышления (effort) выбираются на пульте в карточке «Доступ и подключение»; `TRANSLATION_MODEL` для Claude не используется. По умолчанию Haiku 4.5. После изменения `.env` повторите `npm run configure` и перезапустите сервер. Без ключей доступны вход и настройки; запуск AI отключён.

## Использование

1. Разрешите доступ к микрофону, обновите список устройств и выберите нужный вход.
2. Между сеансами настройте оформление, тему, имена, словарь и бюджет; сохраните изменения.
3. Нажмите «Начать». При непрерывной речи приложение отправляет аудиофрагмент примерно каждые 3 секунды; пауза может завершить его раньше. Затем требуется время на распознавание и перевод. Кнопка «Остановить» завершает захват, в том числе во время запуска.
4. Для телевизора используйте «Открыть экран». Для OBS скопируйте ссылку в источник браузера с размером 1920 × 1080.
5. Во время служения клавиша H скрывает или показывает субтитры, клавиша C очищает экран. Лента перевода показывает русскую фразу и английский перевод; текст хранится только в открытой вкладке.
6. После служения остановите сеанс. При необходимости скачайте метрики без текста.

Ссылка экрана даёт доступ только к субтитрам. Её можно отозвать в настройках; после отзыва замените ссылку в OBS. Микрофон работает на localhost или через HTTPS. Проверка перевода на вкладке тестирования отправляет реальный платный запрос.

## Проверки

```sh
npm test
npm run test:sql
npm run check
npm run lint
npm run build
```

HTTP-проверки запускаются отдельно при работающем сервере на localhost:3000:

```sh
npm run test:http
```

Для HTTP-проверок нужен локальный `.env` без ключей AI. Они меняют настройки и отзывают ссылку зрителя, поэтому запускайте их на тестовой базе. Тесты не отправляют платные запросы.

`npm run build` создаёт сборку; `npm start` запускает её локально через Wrangler. Для внешнего размещения нужны собственная конфигурация Cloudflare, база D1 с миграциями и серверные секреты. `wrangler.local.json` предназначен для локальной базы.

Проверки без API-ключей не подтверждают работу реального распознавания, качество перевода и задержку на телевизоре. Их нужно проверить с микрофоном и выбранными моделями перед использованием на служении.

## Публикация в Cloudflare Workers

Облачная база `church-db` настроена в `wrangler.production.json`. При сборке Vite берёт её ID из этого файла. Разработка через `npm run dev` продолжает использовать отдельную локальную базу из `wrangler.local.json`.

После входа в нужный аккаунт Cloudflare:

```sh
npx wrangler login
npm run db:migrate:prod
npm run deploy
```

Миграции создают таблицы в облачной базе; команда `deploy` собирает и публикует приложение `church-translation`. Адрес `workers.dev` появится в выводе Wrangler.

После первой публикации задайте секреты (каждая команда запросит значение):

```sh
npx wrangler secret put OPERATOR_PASSWORD --config dist/server/wrangler.json
npx wrangler secret put OPENAI_API_KEY --config dist/server/wrangler.json
npx wrangler secret put GEMINI_API_KEY --config dist/server/wrangler.json
# или, если перевод через Claude:
npx wrangler secret put ANTHROPIC_API_KEY --config dist/server/wrangler.json
```

Пароль оператора должен содержать не менее 16 символов. Для обновления кода выполните `npm run deploy`; при добавлении миграций сначала выполните `npm run db:migrate:prod`.

# Проверка propresenter-connector

Проверено 14 сентября 2026 года: [artem-sova-s/propresenter-connector](https://github.com/artem-sova-s/propresenter-connector), commit `98da26f60b5aa80cd730d3e103377144a5d828e2`.
Прочитаны корневой README, все шесть README в docs и XML диаграммы взаимодействия. В дереве также есть изображение диаграммы. Исходного кода, зависимостей, тестов и реализованных API-контрактов нет.

## Что предлагает источник

Поток: голос → whisper.cpp → сервис обнаружения библейской ссылки → лёгкая LLM для нормализации → инструмент показа стиха → ProPresenter REST API → церковный экран.

Разделы документации предлагают описывать архитектуру, API, разработку, эксплуатацию и архитектурные решения. Они пока содержат инструкции для авторов документации, а не готовые инструкции установки.

## Сопоставление с этим приложением

| Область | Текущее состояние | Применение |
| --- | --- | --- |
| Распознавание | Облачный Realtime, микрофон браузера | whisper.cpp требует отдельного локального процесса и нового аудиоадаптера |
| Обработка текста | Упорядоченные финальные транскрипты и перевод | Детектор стихов — отдельная задача; переводчик не должен реконструировать стихи |
| Показ | Браузерный экран / OBS | Коннектора ProPresenter сейчас нет |
| Контракты API | Реализованы маршруты приложения | Добавлено описание текущих контрактов |
| Эксплуатация | Базовый README | Добавлены разбор ошибок, восстановление и ограничения проверок |
| Решения | Не были вынесены отдельно | Зафиксированы границы будущей интеграции |

## Что нужно для полного нового потока

1. Выбрать место запуска whisper.cpp, модель и способ передачи аудио. Измерить распознавание русской речи и задержку на целевом компьютере.
2. Определить контракт финального транскрипта, порядок событий и поведение при разрывах для локального адаптера.
3. Реализовать обнаружение и нормализацию ссылок с проверкой книги, главы и стиха по выбранному библейскому тексту. Не выдавать догадку модели за проверенный стих.
4. Получить версию ProPresenter и фактический API-контракт установки, адрес и порт, способ доступа, выбранный перевод Библии и правила показа.
5. Реализовать локальный коннектор, подавление дублей, обработку недоступности и тесты команд на тестовом экране.

Источник не задаёт перечисленные контракты и параметры. Эта проверка и документация не означают, что whisper.cpp или ProPresenter уже подключены.

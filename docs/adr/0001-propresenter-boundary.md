# 0001. Отдельная граница интеграции ProPresenter

Статус: предложение; реализация коннектора не выполнена.

## Контекст

Текущее приложение переводит речь для браузерного экрана. Репозиторий propresenter-connector описывает другой результат: обнаружить библейскую ссылку и открыть стих в ProPresenter. Он не предоставляет реализацию и API-контракт.

## Предлагаемый подход

Сохранить перевод отдельной операцией. Будущий детектор получает финальные упорядоченные транскрипты; нормализованная ссылка проходит проверку по выбранному библейскому тексту. Коннектор отвечает за доступ к локальному ProPresenter и команды показа. Результаты LLM не должны напрямую становиться произвольными сетевыми командами.

Локальное whisper.cpp — отдельный адаптер захвата/распознавания. Его нельзя включить простой заменой ASR_PROVIDER: текущий клиент устанавливает WebRTC-соединение с облачным сервисом.

## Альтернативы и последствия

Замена всего потока локальным сервисом может обеспечить автономное распознавание, но требует упаковки для целевой ОС, модели, управления процессом и измерений задержки. Добавление только ProPresenter сохраняет текущий ввод, но требует подтверждённого API и сети до установки. Браузерный экран остаётся текущим реализованным выводом.

До реализации нужно определить целевую ОС, версию и адрес ProPresenter, перевод Библии и правила автоматического показа. Затем можно определить проверяемые контракты и тестовый сценарий.

# Архитектура

Браузер оператора получает микрофон и соединяется с сервисом распознавания по WebRTC. Сервер создаёт соединение с серверным ключом; ключ не передаётся браузеру. `lib/live.ts` управляет захватом, очередью, heartbeat и остановкой; `lib/core.ts` упорядочивает финальные транскрипты и разбивает подписи на страницы.

Финальные русские фразы последовательно поступают в `POST /api/control`. `lib/providers.ts` переводит их через выбранного провайдера. Сервер сохраняет текущую подпись, контекст последних четырёх фраз и показатели стоимости в D1. Аудиозапись приложение не сохраняет; текст текущей сессии обрабатывается и хранится отдельно от аудио.

`GET /api/output` возвращает страницу субтитров браузерному экрану или OBS. Доступ к экрану основан на подписанном токене и cookie; отзыв токена увеличивает эпоху зрителя.

В базе одна комната. Идентификатор сессии, номер фразы и токен задания защищают от конкурирующей публикации и позднего ответа после остановки. Heartbeat продлевает аренду сессии; истёкшая аренда обнаруживается при следующем обращении к комнате. Постоянного фонового таймера очистки на сервере нет.

Остановка браузера закрывает аудиодорожки и WebRTC. Сервер обнуляет активную сессию и очищает текст, затем пытается закрыть внешний вызов. Ошибка закрытия не восстанавливает сессию; подтверждение внешнего завершения при этом может отсутствовать.

Локальная разработка использует `wrangler.local.json`; сборка для размещения — `wrangler.production.json`. Cloudflare Worker не запускает локальный бинарник whisper.cpp и сам по себе не имеет доступа к локальной сети церковного компьютера.

`lib/audio-chunks.ts` ограничивает длительность непрерывной речи: после события начала речи клиент примерно каждые 3 секунды отправляет `input_audio_buffer.commit`, не закрывая микрофон и не очищая аудио. VAD сохраняется для более раннего завершения на естественной паузе. До подтверждения предыдущего commit новый не отправляется; отсутствие подтверждения более 10 секунд останавливает сеанс. Переводятся финальные транскрипты фрагментов в аудиопорядке, а не предварительные дельты.

Проверки моделируют минуту речи без события speech_stopped, паузы и гонку VAD/ручного commit. Фактическую задержку и точность слов на границах трёхсекундных фрагментов нужно проверить с реальным микрофоном и выбранной моделью. Короткие фрагменты увеличивают число запросов перевода. Механизм commit описан в [OpenAI Realtime API](https://developers.openai.com/api/docs/guides/realtime-conversations).

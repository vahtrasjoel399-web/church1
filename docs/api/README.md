# Контракты приложения

Все POST принимают JSON и проверяют совпадение Origin с адресом запроса. Ответы ошибок имеют вид `{"error":"сообщение"}`. Ключи AI находятся на сервере.

| Маршрут | Назначение |
| --- | --- |
| `GET /api/auth` | Состояние авторизации, локального режима и настройки пароля |
| `POST /api/auth` | Вход с `password`; `action: "logout"` удаляет cookie |
| `GET /api/control` | Состояние, настройки, провайдеры, показатели и токен зрителя; требует доступа оператора |
| `POST /api/control` | Команды оператора, перечисленные ниже |
| `POST /api/output` | Обмен `token` на cookie зрителя |
| `GET /api/output` | `revision`, `text`, `ttl`, публичные `settings`, `serverNow`; требует cookie зрителя |

## Команды control

| action | Поля и поведение |
| --- | --- |
| `settings` | `settings`: сохраняет настройки между сессиями |
| `screen` | `hidden`, `clear` управляют подписью; `rotate: true` отзывает ссылку зрителя |
| `start` | Создаёт сессию; возвращает `session`, `started` |
| `connect` | `session`, `sdp` (до 20 000 символов); возвращает SDP-ответ |
| `heartbeat` | `session`; продлевает аренду до 25 секунд, проверяет ориентир бюджета |
| `translate` | `session`, целый `seq` от 1, `source` до 2200 символов; возвращает перевод, токены, стоимость и время |
| `stop` | `session` для остановки конкретного сеанса; без него останавливает текущий сеанс оператора |
| `evaluate` | `text` до 1800 символов между сессиями; реальный платный перевод без публикации |

Для перевода номер следующей фразы должен быть `seq + 1`. Повтор последней сохранённой фразы возвращает `duplicate: true`; более старые и пропущенные номера отклоняются. Задания блокируются атомарно в D1; поздний результат не публикуется после смены или остановки сессии.

## Ошибки и повторы

Ошибка входного запроса обычно возвращает 400; доступа — 401/403; конфликта сессии/очереди — 409; локального лимита — 429; отсутствующей конфигурации — 503. Отклонение запроса провайдером перевода возвращается как 502 с исходным статусом в сообщении, таймаут fetch перевода — 504. Поэтому HTTP 502 приложения не обязательно означает HTTP 502 провайдера.

Платные запросы перевода автоматически не повторяются. Сетевой сбой может произойти после обработки запроса провайдером. Браузер останавливает сеанс при ошибке перевода. Переподключения аудио ограничены шестью попытками за сеанс и сопровождаются предупреждением о возможном пропуске речи.

Точных эндпоинтов ProPresenter в исходном репозитории нет. Они не являются частью этого API.

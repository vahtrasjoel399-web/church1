# Разработка

Нужны Node.js 22.13+ и Python 3 для SQL-проверок. Из корня проекта:

```sh
npm ci
npm run configure
npm run db:migrate
npm run dev
```

`configure` создаёт `.env` из шаблона при отсутствии и копирует его в `.dev.vars`. Изменения серверных ключей требуют повторного `configure` и перезапуска. Не добавляйте эти файлы в git.

Клиентская сессия находится в `lib/live.ts`, порядок транскриптов и разбивка подписи — в `lib/core.ts`, адаптеры AI — в `lib/providers.ts`, состояние и доступ к D1 — в `lib/server.ts`, HTTP-маршруты — в `app/api`.

После изменения поведения:

```sh
npm test
npm run test:sql
npm run check
npm run lint
npm run build
```

`npm test` использует подменённые сетевые ответы; SQL-тесты проверяют переходы состояния на SQLite. Они не подтверждают доступность внешней модели. Добавляйте проверки сбоев, порядка событий и остановки при изменениях соответствующих компонентов.

`npm run test:http` запускается отдельно с работающим сервером, тестовой базой и без ключей AI. Он меняет настройки и отзывает ссылку зрителя. Не запускайте его на рабочей сессии.

Проверку реального микрофона, перевода и задержки экрана выполняют отдельно перед служением; она использует внешние сервисы и может тарифицироваться.
